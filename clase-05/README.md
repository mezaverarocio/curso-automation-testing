# Calculadora Modular - Vista estática

Maqueta HTML + CSS de una calculadora web, preparada para ser automatizada con Selenium. No tiene JavaScript ni lógica: solo estructura y estilos.

## Archivos

- `index.html`: estructura de la página (título, formulario, campos, radios y botón).
- `estilos.css`: hoja de estilos externa.
- `selectors.md`: tabla con los selectores de cada elemento.

## Cómo ejecutarla

1. Abrir la carpeta `clase-05`.
2. Abrir `index.html` con el navegador (doble clic, o `Ctrl + O` desde Chrome).

## Cómo verificar los selectores

1. Con la página abierta, presionar `F12` y entrar a la pestaña **Console**.
2. Si Chrome lo pide, escribir `allow pasting` y Enter.
